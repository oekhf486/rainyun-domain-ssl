## 雨云域名侧能拿到什么

- .com：通用，建站首选
- .cn：国内备案场景常用

- .top、.xyz、.club：新型后缀，通常价格更低

价格口径是“成本价”，官方论坛自己也是这么写的。这句话的实际含义是尽量贴近注册局批发价、不额外加一层溢价，它既不等于全市场最低，也不承诺续费永不调整。验证方法很简单：把同一个域名在雨云和别家各查一次，首年价和续费价两个数字都看。

## 免费证书和付费证书怎么选

免费证书够不够用，取决于你介不介意两件事：90 天到期、地址栏没有企业名。

Let's Encrypt 的证书有效期是 90 天，到期必须续。雨云证书中心支持 7 天内的申请发起重新验证，包括手动 DNS 验证的用户，所以续期不是无解的麻烦，但需要一个提醒机制。付费证书通常按年签发，省掉一年三到四次的续期动作，这是它最实际的价值。

第二个区别是身份展示。DV 只验证域名归谁，OV 验证企业主体，EV 的审核最严，浏览器里能显示企业名称。个人博客、工具站、作品集用 DV 完全够；做电商、涉及登录和支付的业务，地址栏那一下的企业名展示对转化有实际影响，这时 3600 元的 OV 才算花在刀刃上。

如果只是几个子域名（blog、api、shop 都在主域名下），别去买多域名证书，直接上通配符。GeoSSL 通配符 740 元，一张覆盖所有二级子域名，比逐个加域名便宜也省事。

## 三条容易踩的坑

**证书下单后不能修改域名信息。** 填错要保护哪个域名，只能重新申请一张，钱不退。买之前把域名拼写核对两遍。
